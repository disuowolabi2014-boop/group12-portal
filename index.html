Course Outline

General Objective 1.0: Know how to Manipulate The Document Object Model

Weeks 1 - 2

Theoretical Content

  • Explain the DOM tree structure and web document rendering.
  • Explain DOM inheritance and node relationships.
  • Describe element selectors: getElementById, getElementsByClassName, querySelector, and createElement.

Practical Content

Utilize DOM traversal methods to navigate parent, child, and sibling nodes. Practice dynamic text, attribute, and style updates.

General Objective 2.0: Understand Events and Event Handling

Weeks 3 - 5

Theoretical Content

  • Analyze event propagation (capturing and bubbling phases).
  • Identify user interface triggers (clicks, keyboard inputs, mouse hovers).
  • Study event listeners, callback execution, and preventDefault() usage.

Practical Content

Attach functional event listeners to HTML components. Build responsive elements using event callback chains and manage default event behaviors.

General Objective 3.0: Comprehend the Basics of Error Handling and Logging

Weeks 6 - 8

Theoretical Content

  • Classify types of JavaScript errors: syntax, runtime, and logical errors.
  • Deconstruct Exception Handling architecture using try and catch logic.
  • Discuss security benefits and returning human-readable messages.

Practical Content

Develop documentation identifying application error states. Implement robust error boundaries utilizing try, catch, and finally blocks.

General Objective 4.0: Know How to Consume Backend APIs

Weeks 9 - 14

Theoretical Content

  • Define JSON objects and master Serialization mechanisms.
  • Study HTTP Request methods: GET, POST, PUT, PATCH, and DELETE.
  • Analyze the JavaScript Fetch API and asynchronous promise paradigms.
  • Review REST architectural principles for network engineering.

Practical Content

Generate standards-compliant dummy JSON schema models. Execute structural network requests to external public API services while managing async rendering streams seamlessly.

General Objective 5.0: Know the Various Frontend Libraries and Frameworks

Week 15

Theoretical Content

  • Distinguish differences between utility Libraries vs structural Frameworks.
  • Evaluate modern ecosystem libraries (React, jQuery) and popular framework architectures (Vue, Angular).
  • Examine efficiency trade-offs and rapid production scaling versus raw native development.

Practical Content

Conduct case studies on architecture selections based on performance constraints and organizational scope limits.
